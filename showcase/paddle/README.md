# Paddle

A Breakout paddle on a 60 ms clock. One three-way choice per tick and the shortest state in the
showcase: this is the game that measures how fast typed decisions can actually be delivered.

## What the model decides

A choice over `left`, `stay`, `right`, described by the distance the paddle would end up from the ball.
The action is the argmax.

## The state, as the model sees it

One real tick, seed 7, 6 steps in:

```text
A paddle must be moved under a falling ball.
```

The state is one constant sentence, and that is a measurement, not laziness. Every sentence added to it
made the model play worse, because the words in the state collide with the names of the options: with "the
ball is 3 columns to the right of the paddle centre, moving down and to the left" it matched the reference
paddle on 10 of 20 sampled positions and answered `left` 18 times; with "3 columns off the paddle centre"
it answered `stay` 15 times; with the bare sentence it matched on 18 of 20. Everything the decision needs
is in the criteria.

## The questions

```json
{
  "move": {
    "type": "choice",
    "instructions": "Move the paddle so that it is under the ball when the ball comes down.",
    "criteria": {
      "left": "further from the ball: the paddle ends 1 column from the ball",
      "stay": "no change: the paddle ends 0 columns from the ball",
      "right": "further from the ball: the paddle ends 1 column from the ball"
    }
  }
}
```

## The shield

Only the walls: a move that would push the paddle off the board becomes `stay`. It never saves a rally.

## The tick

60 ms between decisions. `logic.mjs` is pure and deterministic: the same seed replays the same
episode in node and in the browser, which is what makes the recorded run in `../replay/paddle.json` an exact
rebuild rather than a video.

## What the model actually does

On the fastest clock here the model returns the ball 4.6 times per episode against 0.15 for the random
policy and 12 for the reference paddle, at 32.5 decisions a second measured end to end (29 ms of model,
31 ms of round trip, one question per tick). That rate, not the score, is what this game is for.
The score is worth one honest paragraph of its own. The criteria always say "columns", even at a distance
of one column, and that is a measurement rather than a typo. Agreement with the reference paddle over 20
sampled positions, by phrasing:

| criteria phrasing | agrees with the reference |
| --- | --- |
| `closer to the ball: the paddle ends 2 columns from the ball` | 19 / 20 |
| the same, grammatical at one: `... 1 column from the ball` | 10 / 20 (answers `stay` 9 times) |
| the same, spelled out: `... one column from the ball` | 10 / 20 (answers `right` every time) |
| decimals: `... 1.0 columns from the ball` | 2 / 20 (answers `stay` 17 times) |
| `closer to the ball: gap 1` | 1 / 20 |
| `closer to the ball` with no number at all | 1 / 20 |

One letter is worth about eleven points of score. The model is reading the surface of the sentence, and
paddle is where that shows most plainly.
