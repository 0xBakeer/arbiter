# Dungeon

A rogue-lite written in prose: thirty rooms, a paragraph each, three to five actions and a danger
score. The one game here whose state is native to a text encoder.

## What the model decides

A choice over the actions the room allows (`fight`, `flee`, `loot`, `heal`, `descend`), plus the `danger`
score. A room that leaves one thing to do sends no choice question at all, because a one-option choice is
not a valid question.

## The state, as the model sees it

One real tick, seed 7, 6 steps in:

```text
Room 3 of 30: a collapsed library, shelves fallen against each other. A ghoul with a broken spear blocks the way. You have 9 of 20 hit points, 2 potions and 25 gold.
```

The criteria are sentences about the same paragraph the state carries, verdict first: `deadly: it hits for
up to 7 and you have 5 hit points`. The numbers in them come from the room the generator built, so nothing
in the text is a guess.

## The questions

```json
{
  "move": {
    "type": "choice",
    "instructions": "You are working your way down thirty rooms. Pick the action that gets deeper and richer without getting killed.",
    "criteria": {
      "fight": "safe: it hits for up to 4 and you have 9 hit points, it needs about 2 more rounds to go down",
      "flee": "safe: you run for the stair and leave the room behind, it may land one parting blow of up to 4",
      "heal": "risky: a potion puts back 8 hit points and you have 2, but a ghoul with a broken spear hits for up to 4 while you drink"
    }
  },
  "danger": {
    "type": "score",
    "instructions": "How dangerous is this room for you right now?",
    "criteria": [
      "nothing here can hurt you badly",
      "a fight would cost real blood",
      "one more hit would kill you"
    ]
  }
}
```

## The shield

`shield` vetoes a fight, a loot or a heal in front of something that can kill you in one blow, when there
is another door out of the room, and takes the model's preferred survivable action instead.

## The tick

500 ms between decisions. `logic.mjs` is pure and deterministic: the same seed replays the same
episode in node and in the browser, which is what makes the recorded run in `../replay/dungeon.json` an exact
rebuild rather than a video.

## What the model actually does

This is the game a text encoder should be best at and the one it plays worst: 139.9 points per run behind
the shield, against 256.65 for the random policy and 396.75 for the hand-written one. It fights when it
should walk away, so its runs are short (17 rooms of decisions against 28.55 for random), and the shield
pulls it out of a room that could kill it 3.25 times per run.
The `danger` score is stuck on the middle level: it answers "a fight would cost real blood" for 200 of the
201 safe rooms and for 82 of the 90 rooms where one more hit would have killed, an exact-level match of
0.147 and AUROC 0.545 for the top level. Nothing in the typed answer is tracking how dangerous the room
is, and the prose is not helping it.
