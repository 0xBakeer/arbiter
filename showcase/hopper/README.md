# Hopper

A Flappy-style side-scroller. One noul per tick, "the bird will pass under the gap if it does not flap
now", and the bird does exactly what the number says.

## What the model decides

A single noul. `decide` flaps when it is at or above 0.5 and glides below it. There is no choice question
and no second opinion.

## The state, as the model sees it

One real tick, seed 7, 6 steps in:

```text
A bird must fly through a gap in a wall. The bird is 1.1 rows above the gap, rising. The wall is 13 ticks away.
```

Three facts and nothing else. An earlier encoding also gave the distance to the floor and the ceiling and
the exact sink rate; measured over 24 labelled positions it scored AUROC 0.64 against 0.96 for this one.
The extra sentences were costing the answer, not helping it.

## The questions

```json
{
  "flap": {
    "type": "noul",
    "instructions": "The bird will pass under the gap if it does not flap now.",
    "criteria": {
      "true": "the bird is below the gap and falling",
      "false": "the bird is level with or above the gap"
    }
  }
}
```

## The shield

None. Hopper is the game without a safety net, which is why it is the honest read on the answer: if the
noul is noise, the bird is on the floor within twenty ticks, and the random baseline shows what that looks
like.

## The tick

100 ms between decisions. `logic.mjs` is pure and deterministic: the same seed replays the same
episode in node and in the browser, which is what makes the recorded run in `../replay/hopper.json` an exact
rebuild rather than a video.

## What the model actually does

Hopper is the game the model flies itself: 13.4 walls per episode with nothing between the noul and the
bird, against 0 for the random policy (which is on the floor after 14 ticks) and 26 for the reference
controller, which never dies. The noul separates the reference controller's own answer at AUROC 0.975
over 3,312 ticks, and that is the strongest result in this directory.
It is not calibrated to the 0.5 threshold, and the table shows it: of the 1,850 ticks where the reference
flaps, the model is above 0.5 on 561 of them, so the bird flies low and clips a wall eventually. Ranking
the answer is excellent; reading it as a probability is not.
