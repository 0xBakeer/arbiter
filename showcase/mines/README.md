# Mines

Minesweeper, asked as a batch. Every tick sends up to twelve independent nouls, one per frontier cell,
and the server answers all of them in a single forward pass.

## What the model decides

Up to twelve nouls, one per candidate cell, each carrying that cell's own clues in its own instructions.
The board opens the cell with the highest "safe" answer.

## The state, as the model sees it

One real tick, seed 7, 6 steps in:

```text
Minesweeper on an 8 by 8 board with 10 mines. 24 cells are open and 40 are still unknown. Each question below asks about one unknown cell and carries that cell's own clues.
```

Each question hands the cell the naive estimate a player makes in their head: of the clues touching it,
the one with the least room to spread its mines, as a percentage. Measured over 216 labelled cells that
phrasing scores AUROC 0.79 where the long form ("a 3 with 4 unknown neighbours and a 1 with 3 unknown
neighbours") scores 0.46, and it costs a third fewer tokens. See the honest reading below: the model is
ranking a number it was given, not solving the board.

## The shield

None. Whatever the model calls safest is opened, and a mine ends the episode.

## The tick

250 ms between decisions. `logic.mjs` is pure and deterministic: the same seed replays the same
episode in node and in the browser, which is what makes the recorded run in `../replay/mines.json` an exact
rebuild rather than a video.

## What the model actually does

Twelve nouls go out in one call and come back in 137 ms, which is 87 typed answers a second and the
reason this game is in the showcase. The model opens 38.4 safe cells per board against 32.65 for opening
a random candidate and 50.05 for the single-point solver, which clears 15 of the 20 boards outright.
The ranking is real: AUROC 0.804 over 1,186 labelled cells. But the number those questions were handed —
the naive chance of a mine from the tightest clue — scores 0.898 on its own, so the model is reading that
number back and losing a little of it on the way. It is not solving the board, and the gap between 0.804
and 0.898 is the honest size of what it adds, which is nothing.
